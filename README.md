## Exeat Application for Glorious Vision University
Decompress the Folder and launch the root directory in your Text Editor.  

### `npm install`

Run the nmp install command to install node modules and dependencies

### `npm start`

Runs the app in the development mode.\
Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

The page will reload when you make changes.\
You may also see any lint errors in the console.
